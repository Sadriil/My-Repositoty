# Stone Production — калькулятор столешниц

Веб-приложение с серверным расчётом, SQLite, кабинетами сотрудника и администратора. Каталог перенесён из PRISE 01.10.26 UNPASSED.xlsx: 668 материалов, 38 моек, 8 кромок, 4 бортика. Изображения профилей и моек извлечены из Excel.

## Локальная работа на macOS

Откройте `macos/Start.command` двойным щелчком. Для первого запуска нужен Python 3.12+ с python.org и интернет для установки компонентов. После установки приложение работает локально. Пароль администратора создаётся при первом запуске, данные сохраняются в Application Support. Подробности — в [инструкции для macOS](macos/README.md).

## Запуск

Нужен Python 3.12 или новее. В папке проекта:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python manage.py admin --role admin
uvicorn app:app --host 127.0.0.1 --port 8000
```

Откройте http://127.0.0.1:8000. Команда manage.py запросит пароль администратора интерактивно. Готовых паролей в проекте нет. Для сотрудника: `python manage.py manager --role employee`. Повторное выполнение меняет пароль и завершает старые сессии этого пользователя. В Windows активация окружения: `.venv\Scripts\activate`.

## Возможности

Клиент: поиск материала, до 10 деталей столешницы и 5 стеновых панелей, кромки, бортики и мойки с изображениями, дополнительные работы, доставка, предварительная стоимость, сохранение черновика в браузере, печать в PDF, сохранение заявки на сервере.

Сотрудник: вход с паролем, список заявок, статусы, открытие сохранённого проекта, расчёт со скидкой и ориентировочная себестоимость.

Администратор: дополнительно курс, наценка, акция по мойкам, изменение базовой цены выбранного материала.

Заявки и пользователи хранятся в `runtime/stone.sqlite`. Каталог с внутренними данными не раздаётся как статический файл. Пользовательские расчёты выполняются сервером. Роли проверяются на каждом защищённом API. Сессия действует 8 часов; пароль хранится как scrypt-хеш с солью. Cookie HttpOnly/SameSite Strict, Secure при HTTPS.

## Правила расчёта

- Расчётный курс: `max(базовый курс, 85) × 1.15`.
- Усиление: `50 × расчётный курс × погонные метры`. Дополнительная общая наценка на усиление не применяется — по согласованной формуле.
- Минимальная оплачиваемая площадь столешницы: 1 м²; при ширине менее 560 мм добавляется 40 мм. Стеновые панели без припуска и минимальной площади.
- Цена панели берётся из цены столешницы, как в фактических формулах строк Excel.
- Первые два радиуса и первые 20 км за МКАД бесплатны.
- Акция на мойку сохранена из Excel: при площади столешницы от 1,8 м² применяется значение соответствующего материала, иначе 285 $. Её можно отключить в настройках.
- Исходный внутренний курс 85, наценка 1. Старые заявки сохраняют исходный расчёт; при открытии проекта калькулятор пересчитывает его по текущим ценам.
- Суммы строк округляются до копеек, итог суммируется из отображаемых строк.
- Себестоимость приблизительная, по листу Excel. Расход листов требует проверки. Ручные затраты специальных услуг не включены. Произвольные специальные услуги из Excel пока не представлены в интерфейсе.

## Размещение

Это локально подготовленная версия; публичного адреса пока нет. Для работы клиентов разместите Python-приложение на сервере с HTTPS, обратным прокси и постоянным диском для SQLite. Перед публикацией добавьте реквизиты оператора персональных данных и собственную политику обработки данных. Настройте резервные копии SQLite и ограничение запросов на уровне прокси. Рекомендуемый запуск одного процесса: `uvicorn app:app --host 127.0.0.1 --port 8000 --proxy-headers --forwarded-allow-ips=127.0.0.1`. Прокси должен сохранять Host и передавать X-Forwarded-Proto. SQLite рассчитана на небольшую команду; для нескольких серверов нужна общая БД.

Нет автоматической отправки SMS/email: заявки сохраняются в кабинете. PDF создаётся через диалог печати браузера. Черновики привязаны к текущему браузеру. Фотографии камня не добавлены, так как в исходном каталоге их нет; рисунок столешницы в интерфейсе условный.

## Проверка

```bash
pip install -r requirements-dev.txt
python -m unittest -v test_app
node --check static/app.js
```

Автотесты проверяют согласованные формулы, границы припуска, минимальную площадь, бесплатные лимиты, валидацию, сохранение заявки, роли и защиту от межсайтовых запросов. Визуальная проверка в браузере в среде сборки недоступна.
