# Локальное приложение для macOS

Работает на вашем Mac, открывает калькулятор в браузере по локальному адресу. Интернет нужен при первой установке компонентов. Затем расчёты, каталог, заявки и настройки работают без интернета.

## Запуск из исходников

1. Установите Python 3.12 или новее с https://www.python.org/downloads/macos/ (версия от python.org включает Tkinter).
2. Скачайте ZIP репозитория и распакуйте его.
3. В папке `stone-app/macos` откройте `Start.command`. При первом запуске компоненты автоматически установятся из PyPI.
4. Создайте пароль администратора (от 12 символов). Логин — `admin`.
5. Откроется браузер с приложением. Для настройки цен нажмите «Вход для сотрудников».

Если Finder сообщает, что у файла нет права на запуск, в Терминале выполните `bash ` (со знаком пробела в конце), перетащите файл Start.command в окно Терминала и нажмите Enter.

Небольшое окно Stone Production управляет приложением: повторное открытие браузера, резервная копия, завершение работы. Закрытие вкладки браузера не останавливает сервер; кнопка «Завершить работу» останавливает.

## Где лежат данные

`~/Library/Application Support/Stone Production/stone.sqlite`

В Finder: «Переход → Переход к папке…», вставьте `~/Library/Application Support/Stone Production`. Обновление исходников не удаляет данные. Перед обновлением используйте кнопку «Резервная копия базы». Для восстановления закройте приложение, сохраните текущую базу отдельно и замените `stone.sqlite` своей копией.

Приложение слушает только 127.0.0.1: оно доступно на этом Mac. Другие компьютеры и клиенты из интернета не смогут к нему подключиться. Все локальные пользователи приложения используют одну базу текущего пользователя macOS.

## Самостоятельная сборка .app

На Mac в папке stone-app:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt pyinstaller
bash macos/build.sh
```

ZIP с .app появится в `macos-output`. Внутри сборки есть Python и зависимости: получателю .app отдельно Python не нужен. Сборка предназначена для архитектуры Mac, на котором она создана (`arm64` или `x86_64`). Приложение не подписано сертификатом Apple; macOS может потребовать разрешения запуска через «Системные настройки → Конфиденциальность и безопасность». Не отключайте Gatekeeper глобально.

Готовый бинарный .app в этой Linux-среде не собирался. Перед передачей другим пользователям нужно собрать и проверить его на настоящем Mac.
